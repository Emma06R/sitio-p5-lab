Nave vectorial y proyectiles 2D

Una nave triangular se mueve por la pantalla con el teclado, gira sobre su centro y dispara proyectiles. Todo se calcula con transformaciones geométricas 2D (escala, rotación y traslación) y con vectores de velocidad obtenidos con seno y coseno.

El programa original está hecho en Python con Pygame y se ejecuta en una ventana de escritorio de 800 × 600. Como un navegador no puede ejecutar Pygame, la demostración de abajo es una versión web equivalente hecha con p5.js (js/nave.js) que repite la misma lógica. El código de Python se muestra completo más abajo y se puede descargar.

Código (Python + Pygame)

Programa original completo, elaborado por Ramirez Cruz Josué Emmanuel. Para ejecutarlo en tu computadora necesitas Python y Pygame (pip install pygame) y correr python trabajos_graficacion.py.

# Elaborado por: Ramirez Cruz Josué Emmanuel
# Nave vectorial y proyectiles 2D
import pygame
import sys
import math

# 1.- Inicializar Pygame y configurar la ventana
pygame.init()
ANCHO, ALTO = 800, 600
pantalla = pygame.display.set_mode((ANCHO, ALTO))
pygame.display.set_caption("Simulación Interactiva 2D - Nave Espacial")
reloj = pygame.time.Clock()

# 2.- Función de transformación geométrica 2D
def transformar_vertice(vertice, pos_x, pos_y, angulo, escala=1.0):
    x, y = vertice
    # Escalamiento
    x_esc, y_esc = x * escala, y * escala
    # Rotación (matemática continua)
    rad = math.radians(angulo)
    x_rot = x_esc * math.cos(rad) - y_esc * math.sin(rad)
    y_rot = x_esc * math.sin(rad) + y_esc * math.cos(rad)
    # Traslación al sistema de coordenadas de la pantalla
    return (x_rot + pos_x, y_rot + pos_y)


modelo_triangulo = [(0, -25), (-15, 15), (15, 15)]

# Variables de estado de la nave
pos_x, pos_y = 400.0, 300.0
angulo = 0.0
VELOCIDAD_NAVE = 4.0
VELOCIDAD_GIRO = 4.5
ESCALA = 1.0

# Estructura y control de disparo
proyectiles = []
ultimo_disparo = 0
COOLDOWN_DISPARO = 250  # Milisegundos entre disparos (250 ms)
VELOCIDAD_PROYECTIL = 9.0

# Bucle Principal de Renderizado
ejecutando = True
while ejecutando:
    # 1. Limpieza de pantalla (fondo oscuro)
    pantalla.fill((25, 25, 35))

    # 2. Manejo de eventos del sistema
    for evento in pygame.event.get():
        if evento.type == pygame.QUIT:
            ejecutando = False

    # 3. Lectura de controles por teclado
    teclas = pygame.key.get_pressed()
    tiempo_actual = pygame.time.get_ticks()

    # Rotación sobre su propio centroide (A / D o Flechas Izquierda / Derecha)
    if teclas[pygame.K_a] or teclas[pygame.K_LEFT]:
        angulo -= VELOCIDAD_GIRO
    if teclas[pygame.K_d] or teclas[pygame.K_RIGHT]:
        angulo += VELOCIDAD_GIRO

    # Avance Vectorial Continuo (W o Flecha Arriba)
    if teclas[pygame.K_w] or teclas[pygame.K_UP]:
        rad = math.radians(angulo)
        pos_x += math.sin(rad) * VELOCIDAD_NAVE
        pos_y -= math.cos(rad) * VELOCIDAD_NAVE

    # Reto Opcional (+10 Puntos Extra): Pantalla Envolvente (Screen Wrapping)
    pos_x = pos_x % ANCHO
    pos_y = pos_y % ALTO

    # Generación Dinámica de Proyectiles (Barra Espaciadora)
    if teclas[pygame.K_SPACE]:
        if tiempo_actual - ultimo_disparo >= COOLDOWN_DISPARO:
            # Calcular la posición exacta de la punta (proa) en el espacio de pantalla
            punta_local = modelo_triangulo[0]
            punta_x, punta_y = transformar_vertice(punta_local, pos_x, pos_y, angulo, ESCALA)
            
            # Calcular vector de velocidad del proyectil basado en la orientación de la nave
            rad = math.radians(angulo)
            vx = math.sin(rad) * VELOCIDAD_PROYECTIL
            vy = -math.cos(rad) * VELOCIDAD_PROYECTIL

            # Añadir nuevo proyectil a la lista dinámica
            proyectiles.append({
                'x': punta_x,
                'y': punta_y,
                'vx': vx,
                'vy': vy
            })
            ultimo_disparo = tiempo_actual

    # 4. Actualización y Gestión de Memoria de los Proyectiles
    proyectiles_activos = []
    for p in proyectiles:
        # Mover proyectil
        p['x'] += p['vx']
        p['y'] += p['vy']

        # Verificar si permanece dentro del lienzo de 800x600
        if 0 <= p['x'] <= ANCHO and 0 <= p['y'] <= ALTO:
            proyectiles_activos.append(p)

    # Reemplazar la lista con solo los proyectiles vigentes (libera memoria de los fuera de límites)
    proyectiles = proyectiles_activos

    # 5. Renderizado en pantalla
    
    # Dibujar la nave espacial
    vertices_pantalla = [
        transformar_vertice(v, pos_x, pos_y, angulo, ESCALA)
        for v in modelo_triangulo
    ]
    pygame.draw.polygon(pantalla, (0, 255, 180), vertices_pantalla, 2)

    # Dibujar proyectiles activos
    for p in proyectiles:
        pygame.draw.circle(pantalla, (255, 220, 50), (int(p['x']), int(p['y'])), 3)

    # Intercambiar búferes y mantener 60 FPS (Double Buffering)
    pygame.display.flip()
    reloj.tick(60)

pygame.quit()
sys.exit()

Conceptos que se practican

ElementoQué hace
modelo_trianguloDefine la nave como tres vértices en coordenadas locales, centrados en (0, 0). La punta (proa) es (0, −25): en pantalla el eje y crece hacia abajo, por eso «arriba» es negativo.
transformar_vertice()Aplica a un vértice las tres transformaciones 2D, en este orden: escala → rotación → traslación. Devuelve la posición del vértice en la pantalla.
Rotaciónx' = x·cos θ − y·sin θ y y' = x·sin θ + y·cos θ, con θ en radianes (math.radians convierte los grados).
Avance vectorialCon la nave apuntando a un ángulo θ, el movimiento es x += sin θ · v y y -= cos θ · v. Con θ = 0° la nave sube; con 90° va a la derecha.
Pantalla envolventeReto opcional (+10 puntos): pos_x % ANCHO y pos_y % ALTO hacen que la nave reaparezca por el lado opuesto al salirse.
Disparo y cooldownSolo se crea un proyectil si pasaron al menos 250 ms desde el último (pygame.time.get_ticks()). Nace en la punta ya transformada y su velocidad (vx, vy) sale del ángulo de la nave.
Lista de proyectilesCada frame se mueven y se conservan solo los que siguen dentro del lienzo de 800 × 600. Así la lista no crece sin límite y se libera memoria.
Bucle principalCada vuelta: limpiar pantalla → leer eventos y teclas → actualizar posiciones → dibujar → flip() (doble búfer). reloj.tick(60) limita a 60 FPS.
