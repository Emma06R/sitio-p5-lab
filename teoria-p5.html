Fundamentos de p5.js

p5.js es una librería de JavaScript para creative coding: facilita dibujar, animar e interactuar en el navegador. Está inspirada en Processing, el entorno que también usa Khan Academy, y trabaja sobre el elemento <canvas>.

1. Cómo se incluye en una página

Basta con cargar la librería antes del script propio:

<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.4/p5.min.js"></script>
<script src="js/mi-dibujo.js"></script>

p5.js busca por sí misma las funciones setup() y draw() y crea el <canvas> cuando se llama a createCanvas().

2. Estructura de un sketch: setup() y draw()

function setup() {
  createCanvas(400, 400);   // se ejecuta UNA vez al inicio
}

function draw() {
  background(220);          // se ejecuta ~60 veces por segundo
  ellipse(mouseX, mouseY, 40, 40);
}
  • setup(): configuración inicial (tamaño del lienzo, valores iniciales).
  • draw(): se repite continuamente; es la base de las animaciones. Se controla con noLoop(), loop(), redraw() y frameRate().
  • Los dibujos estáticos de este sitio usan noLoop() porque no necesitan repetirse.

3. Coordenadas y formas básicas

El origen está arriba a la izquierda y y crece hacia abajo, igual que en el canvas.

4. Color y estilo

  • background(r, g, b): pinta todo el lienzo.
  • fill() / noFill(): relleno de las figuras siguientes.
  • stroke() / noStroke() y strokeWeight(): contorno y su grosor.
  • Los colores se pueden dar como escala de grises (fill(200)), RGB (fill(30, 204, 91)), con transparencia (fill(0, 0, 0, 100)) o como texto (fill('#1ecc5b')). Con colorMode(HSB) se trabaja con matiz, saturación y brillo.
  • El estilo es un estado: cada fill() afecta a todo lo que se dibuje después, hasta el siguiente cambio.
  • El orden importa: lo último que se dibuja queda por encima.

5. Variables del sistema, interacción y eventos

  • width, height: tamaño del lienzo.
  • mouseX, mouseY: posición del cursor. frameCount: número de fotograma.
  • mousePressed(), keyPressed(): funciones que p5.js llama cuando ocurre el evento.
  • sin(), cos(), random(), map(): utilidades matemáticas muy usadas en animación.
var x = 0;

function setup() {
  createCanvas(400, 200);
}

function draw() {
  background(255);
  ellipse(x, 100 + 30 * sin(frameCount * 0.1), 40, 40);
  x = (x + 2) % width;                 // avanza y vuelve a empezar
}

function mousePressed() {
  x = mouseX;                          // reinicia en el clic
}

6. Transformaciones

translate(), rotate() y scale() mueven, giran y escalan el sistema de coordenadas. push() y pop() guardan y restauran el estilo y las transformaciones, para que un cambio no afecte al resto del dibujo.

7. Modo global y modo instancia

En el modo global (el que usamos aquí) las funciones de p5.js están disponibles directamente en window. En el modo instancia se encapsula el sketch en un objeto, lo que permite tener varios sketches en una misma página sin que se mezclen:

const sketch = (p) => {
  p.setup = () => { p.createCanvas(400, 400); };
  p.draw  = () => { p.ellipse(200, 200, 100, 100); };
};
new p5(sketch, 'contenedor');

8. Relación con <canvas>

Cuando se ejecuta createCanvas(), p5.js inserta un <canvas> en la página (o dentro del elemento indicado con .parent('id')) y usa su contexto 2D internamente. Cada llamada como ellipse() se traduce en instrucciones de la API Canvas 2D. Si hace falta, el contexto original es accesible con drawingContext. Consulta la teoría de canvas para ver las equivalencias.

9. De Khan Academy a una página web

Khan Academy ejecuta el código dentro de su propio entorno. Para llevarlo a un sitio web estándar se hicieron estos cambios:

  1. Se carga p5.js desde una etiqueta <script>.
  2. El código que estaba suelto se coloca dentro de function setup() { ... }.
  3. Se crea el lienzo con createCanvas(400, 400) y se asocia a un <div id="lienzo"> con .parent('lienzo').
  4. Se añade background(255), porque el lienzo de p5.js parte transparente y en Khan Academy el fondo es blanco.
  5. Se usa noLoop() en los dibujos estáticos para que se dibujen una sola vez.
