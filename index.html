Dibujos y animaciones con p5.js

Colección de proyectos creados originalmente en Khan Academy y adaptados a un sitio web con HTML, CSS y JavaScript estándar. Cada dibujo se renderiza en un elemento <canvas> mediante la librería p5.js.

Proyectos

  • Rana loca

    Una rana dibujada con elipses, variables y colores RGB.

  • Dientes de conejo

    Un conejo con orejas, ojos, boca y dientes parametrizados.

  • ¿Qué hay de cena?

    Un plato con comida sobre un fondo gris.

  • Día nevado soleado

    Un muñeco de nieve bajo el sol, sobre un suelo helado.

  • Muñeco de nieve que saluda

    El muñeco con los brazos levantados, ahora con botón para saludar.

  • El sol que explota

    Animación: un sol que sube y crece en cada fotograma con draw().

  • Nubes que se separan

    Animación: dos nubes se alejan mientras el sol crece detrás.

  • Estrella en el cielo nocturno

    Una estrella amarilla sobre el cielo, posicionada con variables.

Sobre este sitio

  • HTML estructura cada página con etiquetas semánticas (<header>, <nav>, <main>, <section>, <footer>).
  • CSS define el diseño, la rejilla de tarjetas y el árbol del inspector (css/styles.css).
  • JavaScript contiene un archivo por dibujo y el script del inspector del DOM (carpeta js/).
  • Las secciones teóricas explican el uso de <canvas> con su contexto 2D y los fundamentos de p5.js.
