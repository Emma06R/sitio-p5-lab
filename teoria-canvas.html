La etiqueta <canvas> y el contexto 2D

El elemento <canvas> de HTML5 es una superficie rectangular de píxeles sobre la que JavaScript puede dibujar gráficos, juegos y animaciones. Es la base sobre la que p5.js crea sus dibujos.

1. ¿Qué es <canvas>?

Por sí solo, <canvas> es un contenedor vacío: no dibuja nada hasta que un script obtiene su contexto de renderizado y le envía instrucciones. A diferencia de SVG, que conserva cada figura como un elemento del DOM, el canvas es un mapa de bits: una vez pintada, una figura se convierte en píxeles y el navegador ya no recuerda que era un círculo o un rectángulo.

<canvas id="lienzo" width="400" height="400">
  Tu navegador no soporta canvas.   <!-- contenido alternativo -->
</canvas>
  • width y height: tamaño del lienzo en píxeles. Si se omiten, el valor por defecto es 300 × 150.
  • El texto interior se muestra solo en navegadores que no soportan canvas y sirve como contenido alternativo; también puede ayudar a la accesibilidad junto con atributos como aria-label.
  • Cambiar el tamaño con CSS escala la imagen ya dibujada; cambiar los atributos width/height modifica la resolución real (y borra el contenido).

2. El contexto de renderizado

El contexto es el objeto con los métodos de dibujo. Se obtiene con getContext():

const canvas = document.getElementById('lienzo');
const ctx = canvas.getContext('2d');   // CanvasRenderingContext2D

El parámetro indica el tipo de contexto. Un mismo canvas solo puede tener un tipo de contexto:

ValorResultado
'2d'Contexto de dibujo bidimensional (CanvasRenderingContext2D). Es el que usan los proyectos de este sitio.
'webgl', 'webgl2'Gráficos 3D acelerados por GPU.
'bitmaprenderer'Muestra imágenes de tipo ImageBitmap.
'webgpu'API gráfica moderna basada en WebGPU.

Si el navegador no soporta el contexto pedido, getContext() devuelve null; por eso conviene comprobarlo antes de dibujar.

3. Sistema de coordenadas

El origen (0, 0) está en la esquina superior izquierda. El eje x crece hacia la derecha y el eje y crece hacia abajo. Es el mismo sistema que usa p5.js, por eso ellipse(200, 250, ...) en Khan Academy aparece en la mitad inferior de un lienzo de 400 × 400.

4. Dibujar con el contexto 2D

Rectángulos

ctx.fillStyle = 'rgb(139, 69, 19)';
ctx.fillRect(130, 180, 80, 40);     // relleno: x, y, ancho, alto
ctx.strokeRect(130, 180, 80, 40);   // solo contorno
ctx.clearRect(0, 0, 400, 400);      // borra un área

Trazados (paths)

Las demás figuras se construyen con un trazado: se inicia con beginPath(), se describe con moveTo, lineTo, arc o ellipse, y finalmente se pinta con fill() y/o stroke().

ctx.beginPath();
ctx.ellipse(200, 250, 100, 50, 0, 0, Math.PI * 2); // x, y, radioX, radioY, rotación, inicio, fin
ctx.fill();

ctx.beginPath();          // una línea (como la boca del conejo)
ctx.moveTo(150, 200);
ctx.lineTo(250, 200);
ctx.stroke();

Observa que ellipse() del contexto recibe radios, mientras que ellipse() de p5.js recibe el ancho y alto totales.

Estilos

  • fillStyle y strokeStyle: color de relleno y de contorno ('#1ecc5b', 'rgb(30,204,91)', gradientes...).
  • lineWidth: grosor de las líneas. globalAlpha: transparencia.
  • createLinearGradient() y createRadialGradient(): degradados.

Texto, imágenes y transformaciones

  • fillText(texto, x, y) y la propiedad font para escribir.
  • drawImage(img, x, y) para insertar imágenes.
  • translate(), rotate(), scale() modifican el sistema de coordenadas; save() y restore() guardan y recuperan el estado.

5. Animación

El canvas no tiene "ciclo" propio. Para animar se repite este patrón con requestAnimationFrame(): borrar el cuadro anterior, actualizar variables y volver a dibujar. Esta es exactamente la tarea que p5.js automatiza con draw().

7. Demostración: la rana con Canvas 2D puro

Este lienzo reproduce la rana del primer proyecto sin p5.js, usando solo getContext('2d'). Debajo, una pelota que rebota con requestAnimationFrame().

Código (js/canvas-demo.js)

/* Demostraciones con la API Canvas 2D pura (sin librerías). */
(function () {
  // ---------- 1) La rana, dibujada sin p5.js ----------
  var canvas = document.getElementById('demo-canvas');
  if (canvas && canvas.getContext) {
    var ctx = canvas.getContext('2d');

    // Equivalente a ellipse(x, y, ancho, alto) de p5.js
    function elipse(x, y, ancho, alto) {
      ctx.beginPath();
      ctx.ellipse(x, y, ancho / 2, alto / 2, 0, 0, Math.PI * 2);
      ctx.fill();
    }

    ctx.fillStyle = '#ffffff';
    ctx.fillRect(0, 0, canvas.width, canvas.height);   // background(255)

    ctx.fillStyle = 'rgb(30, 204, 91)';                // fill(30, 204, 91)
    elipse(200, 150, 200, 100);                        // cara
    elipse(150, 100, 40, 40);                          // cuenca izquierda
    elipse(250, 100, 40, 40);                          // cuenca derecha

    ctx.fillStyle = 'rgb(255, 255, 255)';
    elipse(150, 100, 30, 30);                          // ojo izquierdo
    elipse(250, 100, 30, 30);                          // ojo derecho

    ctx.fillStyle = 'rgb(0, 0, 0)';
    elipse(200, 150, 100, 50);                         // boca
    ctx.fillRect(145, 95, 10, 10);                     // pupila izquierda
    ctx.fillRect(245, 95, 10, 10);                     // pupila derecha
  }

  // ---------- 2) Animación con requestAnimationFrame ----------
  var lienzo2 = document.getElementById('demo-animacion');
  if (lienzo2 && lienzo2.getContext) {
    var c = lienzo2.getContext('2d');
    var x = 40, vx = 3, radio = 22;

    function cuadro() {
      c.clearRect(0, 0, lienzo2.width, lienzo2.height);   // borra el cuadro anterior
      c.fillStyle = '#38bdf8';
      c.beginPath();
      c.arc(x, lienzo2.height / 2, radio, 0, Math.PI * 2);
      c.fill();

      x += vx;
      if (x > lienzo2.width - radio || x < radio) { vx = -vx; }   // rebote
      requestAnimationFrame(cuadro);
    }
    cuadro();
  }
})();
